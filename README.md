# Tooread

**Tooread** is a web-based platform for reading Light Novels, created as a personal learning project to explore and practice full-stack web development.

The main goal of Tooread is to provide a simple and comfortable environment for users to discover and read Light Novels through a clean and straightforward interface. The project focuses on building the basic structure of a modern web application, from displaying content on the frontend to processing data and requests through the backend.

## About The Project

Tooread was created during my journey of learning software development. Instead of focusing only on individual programming languages or isolated exercises, this project allows me to understand how different technologies work together to form a complete web application.

The project includes a frontend for users to interact with the website, a backend responsible for application logic and APIs, and a database used to store and manage application data.

Through developing Tooread, I am able to practice concepts such as frontend development, backend development, REST APIs, database management, data handling, and communication between the frontend and backend.

## Features

Some of the main features planned or implemented in Tooread include:

* Browse and read Light Novels through a web interface
* Display information about novels and chapters
* Navigate between chapters while reading
* Manage and retrieve novel-related data from the backend
* Store application data using MySQL
* Communicate between the frontend and backend through APIs
* Provide a simple and user-friendly reading experience

The project is still under development, so additional features and improvements may be added over time.

## Technologies

### Frontend

* **HTML5** — Used to structure the website and its content.
* **CSS** — Used to customize the appearance and layout of the website.
* **Bootstrap 5** — Used to build a responsive and consistent user interface.
* **JavaScript** — Used to add interactions and handle communication with the backend.

### Backend

* **Java** — The main programming language used for the backend.
* **Spring Boot** — Used to build the backend application, handle business logic, create APIs, and communicate with the database.

### Database

* **MySQL** — Used to store and manage information such as novels, chapters, users, and other application-related data.

## Project Structure

Tooread is separated into different parts based on their responsibilities.

The **frontend** is responsible for everything users see and interact with, including the navigation, novel information, reading interface, and other user-facing components.

The **backend** handles the application's main logic. It receives requests from the frontend, processes the required operations, communicates with the database, and returns the appropriate data through APIs.

The **database** stores the application's persistent data and allows the backend to retrieve, create, update, and manage information when necessary.

This separation helps me understand the basic architecture of a full-stack application and how different layers communicate with each other.
